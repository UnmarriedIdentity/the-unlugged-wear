3. FIGMA SPECIFIC HIT POINTS & STATE SIMULATION (URL QUERY PARAMS)
--------------------------------------------------------------------------------

A. LOGIN PAGE STATES (/ or /login)
- /?state=default
  Figma Frame: 1:20816 ("0 1 0 Log In")
  Description: Clean initial login view with empty fields.

- /?state=filled
  Figma Frame: 1:20776 ("0 1 1 Log In - Filled")
  Description: Pre-filled credentials (contactstylehub@gmail.com / stylehubforlyfe).

- /?state=error
  Figma Frame: 1:20725 ("0 1 2 Log In - Error Password")
  Description: Red error container with warning message "Password comparisson failed".

- /?state=reset
  Figma Frame: 1:20710 ("0 1 3 Reset Password")
  Description: Clean password reset input view.

- /?state=recovery
  Figma Frame: 1:20690 ("0 1 4 Recovery email sent")
  Description: Success card confirmation with green badge.

B. CREATE ACCOUNT (SIGN UP) STATES (/signup)
- /signup?state=default
  Figma Frame: 1:20984 ("0 1 0 Sign Up")
  Description: Clean initial sign up form with Username, Email, Create password,
               Confirm password, and Terms & Privacy agreement checkbox.

- /signup?state=filled
  Figma Frame: 1:20920 ("0 1 1 Sign Up - Filled")
  Description: Pre-filled state (Username: "Jessicha Smith",
               Email: "jessichasmith94@gmail.com", Masked passwords, Checked box).

- /signup?state=verify-empty
  Figma Frame: 1:20890 ("0 1 2 Sign Up - Email Verification")
  Description: 4-digit OTP empty input boxes (56x56px), resend code prompt,
               and "Back to login" navigation.

- /signup?state=verify-filled
  Figma Frame: 1:20856 ("0 1 3 Sign Up - Enter code")
  Description: Active verification state with filled code digits "3 3 4 2".

C. DEDICATED VERIFICATION HIT POINTS (/verify)
- /verify
  Figma Frame: 1:20890 (Default empty 4-digit OTP boxes)

- /verify?state=verify-filled
  Figma Frame: 1:20856 (Pre-filled code "3 3 4 2")

D. DEDICATED PASSWORD RESET HIT POINTS (/reset-password)
- /reset-password
  Figma Frame: 1:20710 (Password reset form)

- /reset-password?state=recovery
  Figma Frame: 1:20690 (Recovery email sent success confirmation)
