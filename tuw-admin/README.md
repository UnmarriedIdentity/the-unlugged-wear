# tuw-admin

Staff admin: products, orders, fulfillment, content and reports. Use Urbanist and the V2 admin design system.

This is a folder scaffold, not a runnable application. Page components, root layouts, dependencies, integrations, authentication and tests must be implemented. Empty folders contain .gitkeep so they survive version control. Configuration files are starting templates. Both applications will connect to the same Supabase database with separate server-side access checks.
